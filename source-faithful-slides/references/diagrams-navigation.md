# 图示保留与部位导航

在源报告含解释图，或简报反复展开同一系统时读取。

## 图在草图中承担什么

先辨认图的解释作用、关键对象、输入输出、方向和限定，再决定保留原图、裁切或忠实重绘。盘面可用原生彩格重绘；结构图、仪表等须保留其图形角色，不能改成几格文字而丢失含义。重绘要能回指源图或源文依据，不伪造数据、盘面状态或因果关系；缺乏依据时标明具体缺口。

逐页 Mermaid 须交代图的位置、相对大小、图形角色及阅读顺序，并让制作者看见图：按环境选择图像节点、足够表达关系的图形区块，或与草图页 ID 对应的配套预览。文字标签可以辅助，单独一行“配图：文件名”不算设计。图形复杂时不必硬译成 Mermaid 节点，保留实际图示并在草图中安排其空间。

图片和重绘素材放本次授权工作区，逐页表记录可解析路径及来源；不要求写入原报告目录。先在实际使用的渲染器检查语法、图片路径和加载权限，再选表达方式；不指定 Mermaid 版本。预览无法载入图像时改用可显示的图形区块或配套预览，交付前检查打开后的实际图像，不把源码中有路径当作显示成功。

## 地图与定位

反复讲同一系统、听众容易失去当前部位时使用地图；页数或部件数量仅作提示。地图以具体输入到输出的部件关系为主，保留空间与结构含义，避免把所有部件画成抽象线性串联。后续技术页使用同一套部件、关系及颜色的简化定位图，当前部位亮起、其余变淡。

在逐页表旁维护一份紧凑的部位表：`部位 ID → 显示名称 / 图形角色 / 来源依据`。逐页表显式记录该页涉及的部位 ID 与亮起部位；跨部位页可以亮起多个，有意讲全局则明确写“全局”。不根据标题关键词或正则推断部位。非技术页不需要定位时写“无”。

采用导航后，逐张技术页核对三个证据：正文所讲部位、逐页表的 ID、实际图中亮起部位。三者不一致或漏定位就修正，不能因标题看似正确放行。连线语义与图例按 [视觉规范](visual-preferences.md) 处理；导航图与其主图共用对应含义。

## 源图去向

把源图去向并入现有章节映射：`源文件/图号或位置 → 正文/附录/合并/省略 → 目标页 ID（省略可无） → 理由`。合并时说明哪一图保留了各自的解释作用，省略时说明信息是否已由正文或其他图覆盖。每页配图字段分别列“必要解释图”和“装饰图”，没有就写“无”；不为填栏而添加图片，也不要求每张源图都上屏。
