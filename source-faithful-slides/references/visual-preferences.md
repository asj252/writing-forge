# 视觉规范（示例默认值）

本文件里的配色、字体、阈值与边框样式都是**示例默认值**。用户提供的模板、品牌规范或明确指示优先；用户选定过的样式记下来后沿用，不退回这里的默认。

## 风格选择

以已确认的版本为主，小幅调整。不要在用户没有要求时把整稿改成统一的灰色大卡片或换掉整体视觉系统。

浅灰接近白色，用来帮助分块，不占据全页。使用白底、少量色块、文字层级、留白及必要的框线形成结构。不同页按内容选布局：双向关系、对照、时间轴、完整案例表等，减少重复感。

### 整稿配色与版型节奏

用户给了纯色页比例的上限时（示例：**严格低于 40%**），按下面的口径统计。按正文主体的配色判断：主要内容只用一套主色、辅以白灰中性色，计为纯色；第二种颜色须在正文主体承担实质内容区分，才计双色/多色。品牌页眉、页码、短装饰线或小点缀不能把纯色页算成双色。

逐页记录分类；默认分母为本轮完整交付稿所有页面（含封面、章节页、附录），如用户限定统计范围则按其要求。交付时说明口径、分母、纯色页数及任何例外/排除理由，不自行用排除页面凑比例。例：60 页稿里 18 页纯色，18/60 = 30%，低于 40% 通过；恰好 40% 不通过。

看连续页缩略图，检查是否重复套用同一版型、色块与阅读节奏；比例达标也需按实际内容调整，不能仅换小点缀过关。用了现成插画素材时，连续页节奏另按 [已有素材与插画](visual-assets.md) 检查。

## 字体

- 示例：PPT 中英文、拉丁字母与数字显式使用一款西文字体（如 **Montserrat**），包括标题、版本号、表格、图表、页码；不能只设置主题后假设混排已正确。
- 中文使用模板指定的中文字体；模板没有指定时，示例为 **Microsoft YaHei**。
- 混排按文字段设置字体，中文保留中文字体；不要对整段强制西文字体导致中文回退。
- Mermaid 的字体栈与 PPT 一致（示例：`Montserrat, Microsoft YaHei, sans-serif`），由渲染配置设定，版面描述与 `build` 不管字体；不能以浏览器回退结果证明 PPT 字体设置正确。
- 字号沿用当前模板；内容溢出时优先处理结构和换行，不能为了塞字不断缩小正文。

## 配色角色（示例）

先按**角色**定颜色，再选具体色值。下表的色值是一套示例；有模板或品牌规范时，把每个角色换成对应的颜色，角色本身保留。

| 用途 | 示例颜色 | 使用方式 |
|---|---|---|
| 主标题、核心强调 | 主色 `#2B4C7E` | 主色 |
| 顶部色带、少量强调 | 强调色 `#3E7CB1` | 不扩散为大面积内容背景 |
| 深色标题 | 深色 `#1B2A41` | 按模板使用 |
| 次级主色 | `#5B7DB1`、`#8FA9CF` | 需要区分层级时使用 |
| 辅助色 | `#A9BCD9` | 次要图形与辅助标记 |
| 浅色内容色块 | `#E8EEF6` | 核心角色或内容组 |
| 正文 | 深灰 `#404040` | 默认正文色 |
| 次要说明、出处 | 中灰 `#6D6D6D` | 不承担关键正文 |
| 分组框线 | 浅中灰 `#B8B8B8` | 细线、克制 |
| 分隔线 | 浅灰 `#D6D6D6` | 结构辅助 |
| 浅灰分区 | `#F2F2F2` | 局部底色、汇总条 |
| 画布 | 白 `#FFFFFF` | 主背景 |
| 黑色 | `#000000` | 必要时使用，不替代整套层次 |

模板自带的其他颜色（如角色区分色、点缀线）保留模板实际值，不当成用户另给的品牌色；无理由不新增颜色。

## 简报语义色整组组合审查（#61）

简报中的核心强调色承载特定认知功能，**必须按「文字、底色、边框、图标」整组组合审查**，不得仅对单字或关键词单列替色：

1. **整组用途先行**：
   - **青绿（`signal-teal`，结论色）**：用于核心定性、已证结论、正面进展、做得到的能力。文字与底色应形成结论感。
   - **洋红（`alert-magenta`，警示色）**：用于风险、警示、失败分支、代价、必须注意的陷阱。整组必须传达醒目的阻断或警惕意图。
   - **浅蓝（`limit-blue`，限定色）**：用于范围限定、成立前提、证据口径、采样规模或估算标签。表达「在此限定下成立」，而非否定或正面结论。
2. **合法搭配组合与标准结构组件**：
   - 警示信息：允许「浅洋红底 `#FCE8F2`＋洋红边框／左缘 4 px 色条 `#E00F78`＋深灰文字」或「透明底＋洋红文字」；
   - 限定信息：允许「浅蓝底 `#EAF5FA`＋浅蓝边框／左缘 4 px 色条 `#59B2D1`＋深蓝/深灰文字」；浅蓝一般作背景或边框，不直接作正文字色（避免对比度不足）；
   - 结论信息：允许「浅青绿底 `#E6F5F3`＋青绿边框／左缘 4 px 色条 `#009B8A`＋深青绿/深灰文字」或「青绿文字强调」；
   - 结构节点与重点句标记（模板配套组件）：并列／承接步骤节点可用浅灰紫底（`struct-node-bg` `#F3F1F6`、无外框、左缘 4 px `ink-soft` `#6B6377` 色条，节点间配实心箭头承接）；每页至多一句核心带走句可用模板黄荧光笔底色（`highlight-yellow` `#F4EC51`＋深灰字，不作字色）。
3. **禁止冲突组合**：
   - **严禁「洋红警示字＋浅蓝限定底」**：底色不能误当无害中性底，浅蓝底传达限定/条件，洋红字传达危险/警示，二者叠加会造成认知冲突；
   - 空背景文本框不能自动视作中性背景，必须检查其在整页卡片或父容器中的叠加底色；
   - 严禁为了“凑齐三色”在没有限定或风险的页面强加颜色，也不得按单个关键词全局自动替色；
   - 区分图形类别色（数学图表中的蓝/紫原基底与主要变换）与简报语义色，禁止全局文本替色误伤图表类别编码。

## 选定样式的记录与沿用

用户在几个备选样式里明确选定一种后，记下「选中项、适用部位、保留项」，后续沿用，不退回自己偏好的方案，也不把未选的备选混进定稿。

下面是一种常用的**分组框**样式示例（浅灰圆角虚线框），以及它的语义约定：

- 用途：解释段落的归组，例如一条架构关系链。
- 透明或白色内部；细灰线 `#B8B8B8`，参考线宽 1.2px、圆角半径 16px（基于 1280×720 页面）。
- 虚线**分组框**表示内容归组，不表示未完成、未来或不确定；必要时在图例/说明中澄清。它与箭头、关系线的语义分开。
- **连线**的颜色与虚实可区分内容含义，如不同做法或可选路径；页面须有可读图例。同类线在对应图示系统（含其导航缩图）中保持语义一致，不把此约束扩大为全稿所有不同图表必须共用同一套线义。
- 框内有缩排，框外标题与结论保持独立。不要让边框紧贴文字或覆盖内容。
- 不擅自加整圈装饰框或恢复用户没选的装饰；模板页眉原有的装饰可保留。
- Mermaid 示例：`stroke:#B8B8B8,stroke-width:1px,stroke-dasharray:5 5,rx:16,ry:16`。不同渲染器圆角支持可能不同，实际 PPT 使用原生圆角形状。

## 版式骨架、双页眉变体与按需强化规范（`Presentation-VioletReady-v6` 基准）

选用 `Presentation-VioletReady-v6` 作为研究与工程简报基准模板时（基于 16:9 画布 `1280 × 720 px`，`1 px = 9525 EMU`；若选用 `Teaching-v2` 或用户已确认的其他定制样式，保留各自模板与样式边界，不跨模板静默混用），遵守以下五项几何与层级硬规范：

1. **三套浅底高对比封面范式（`p01–p03`）**：
   - 摒弃沉闷的深黑紫全屏背景，统一采用高对比浅底（`#FAF8FC` 或浅紫白渐变）；`p01`（左竖条单栏）与 `p03`（右侧淡化插画＋底部三格问答）左侧统一采用轻盈三层浅紫竖条（`x=0..14` `#57068C` 细边＋`x=14..96` `#E6DCF5` 浅丁香紫＋`x=96..132` `#F2ECFA` 柔光过渡带），`p02` 采用明快浅渐变底双栏卡片；
   - 封面上的核心回答卡与适用边界卡**对彩色大框本身用左缘或顶缘 `6–8 px` 实心色条强化**（`p01–p02` 为 2 张核心大卡，`p03` 为底部 3 张问答钩子卡），不在封面大卡内再套碎小框。
2. **双页眉变体体系（Two Header Variants）**：
   - **变体 A（常规编号徽章页眉，如 `p04`、`p07–p40`）**：顶部 `12 px` 品牌紫条；左上编号徽章 `x=38, y=34, w=76, h=76`；浅紫渐变标题带 `x=94, y=34, w=1146, h=76`（`#EEE6F3` 渐层至白）；主标题框宽扩展至 `990 px`（确保单行不折行），正文从 `y=124..132 px` 起排。
   - **变体 B（通栏章节胶囊导航页眉，如 `p05–p06`）**：用于多模块汇报的章节推进页、机制总览或核心对比矩阵页。几何规格：（1）顶部铺满 `y=0..166 px` 浅丁香紫通栏（`#F3EEF8`）配顶缘 `6 px` 品牌紫封边条（`#57068C`）；（2）左上置圆角章节胶囊（`x=55, y=14, w=560, h=26, radius=13`，底 `#E4D5F0`、字 `#57068C` `11pt` 粗体，标示 `SECTION X · 章节副标题`）；（3）下方置 `24.5pt` 主标题（`x=55, y=44, w=1000, h=50`），右上置品牌徽章（`y=16..88` 区间，位于分割线上方）；（4）`y=102` 设左粗紫（`266 × 4 px` `#57068C`）接右细灰（`904 × 1.5 px` `#D8D2E1`）双色分割线；（5）`y=116` 横跨 `x=55..1225` 等距排布 6 枚圆角章节进度胶囊（`w=180, h=34, gap=18, radius=17`），当前所在章节以实心 `#57068C` 紫底白字（`12pt` 粗体）高亮，其余章节以 `#E4D5F0` 浅紫底紫字伴随；下方正文从 `y=176 px` 起排。
3. **按需强化原则与色条层级兼容规则（Selective Reinforcement）**：
   - **外层焦点强化配额**：左缘或顶缘 `6–8 px` 实心强化色条属高权重焦点，**严禁在 4 格及以上的多卡网格、长列表或全页彩框上无差别全员加粗色条**。常规内容页（如 `p04`、`p06`、`p09–p11`、`p16–p22`、`p24–p30`、`p32–p41`）仅挑 **1–2 个核心突破点、主统计检验项、目标阶段或关键失真警示外框** 强化；双焦点卡配底部独立收束条或第三焦点/三栏并列专题卡的页面（如 `p03`、`p05`、`p07`、`p15`、`p23`、`p31`）外框强化不超过 **3 处**；专用结构图表页（`p08` 时间轴色块、`p12` 四象限右侧 4 条策略图例卡、`p13` 三泳道阶段关口图、`p14` 8 格趋势小图顶色带）按各自图表结构编码，不套用常规卡片配额；
   - **细色条与内嵌子框兼容规则**：上文「合法搭配组合与标准结构组件」中的左缘 `4 px` 语义色条或 `struct-node-bg` 左缘 `4 px` 灰紫色条，仅用于未加 `6–8 px` 粗色条的独立提示框、独立收束条或步骤节点（同一容器不得叠加双色条）；其余普通并列对比外卡、次要说明卡，以及**凡采用「上文＋下内嵌子框」结构的单张带框彩色母卡**（如 `p04` 左三卡、`p05` 左证据卡、`p16`、`p20`、`p27`、`p30`、`p32`、`p34`、`p35`、`p40`）内部嵌套的白底/浅底子框一律采用 `1.0–1.25 pt` 清爽细边框，**严禁在单张彩色母卡的内嵌子框上叠加任何 `4 px` 或 `6–8 px` 内层色条**（注：包裹多个独立节点或子卡的区域归组容器——如 `p04`/`p05` 的虚线分组框、`p13` 的泳道分区框、`p17` 的阶段高亮列底带——属分区背景而非单张彩色母卡，其内部独立步骤节点、结论条或阶段卡可按各自组件规则带色条）。
4. **全页等距网格、框内逐行弹性字号与嵌套子框呼吸间距**：
   - **等距网格**：外层卡片与上方分栏标题线、相邻卡片、下方通栏结论条（`x=55, y=616, w=1170, h=46`）及页脚分隔线（`x=55, y=676, w=1170, h=2`）之间保持统一等距（标准 `12–16 px`，如 `14 px` 网格）；双栏布局左栏 `x=55, w=578`、中隔 `14 px`、右栏 `x=647, w=578`（总宽 `1170 px`）严格对齐。
   - **逐行弹性字号与呼吸带**：含嵌套子框的单张彩色母卡，上半部文字按「小号粗体分类标签（`12.5–13.5pt`）→ 大号核心判断/关键数字（`18.5–21pt`）→ 中号结论说明（`13.5–14.5pt`）」逐行弹性字号排布；**上半部末行文字底边与下半部内嵌子框顶边之间必须预留 `12–16 px` 视觉呼吸带**，严禁子框紧贴上文或上下留白失衡。
5. **结构化矩阵替代粗糙原生表格与高难图表版型**：
   - 多维职责/方案对照、逐帧轨迹、森林图区间与证据缺口表优先采用圆角分层行卡（矩形＋文本框）或精控边距与 `0.75pt` 细灰格线的结构化矩阵（见模板 `p06`、`p26`、`p29–p30`、`p34–p36`、`p39`），彻底消除单元格单字折行与跨框遮挡；
   - 甘特图按项目阶段采用语义色圆角药丸条配右侧进度标签（`p11`）；四象限矩阵将四角文字缩为紧凑角落徽章，坐标轴停在绘图区内不遮挡散点项目（`p12`）；阶段评审关口采用顶部圆角标签卡＋语义徽章（`p13`）；多组趋势小图（Small Multiples）采用顶栏标题＋浅底绘图区双层卡片并高亮峰值点（`p14`）。

## 局部修改的判断

“更细化配色”表示优化原有颜色角色与少量分区，不等于换掉整体构图。“更集中”表示保留完整论证、减少无意义拆页，不等于堆满所有资料。“减少重复”表示根据内容变化布局，不等于每页重建视觉系统。
