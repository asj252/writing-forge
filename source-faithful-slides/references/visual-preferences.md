# 视觉规范（示例默认值）

本文件里的配色、字体、阈值与边框样式都是**示例默认值**。用户提供的模板、品牌规范或明确指示优先；用户选定过的样式记下来后沿用，不退回这里的默认。

## 风格选择

以已确认的版本为主，小幅调整。不要在用户没有要求时把整稿改成统一的灰色大卡片或换掉整体视觉系统。

浅灰接近白色，用来帮助分块，不占据全页。使用白底、少量色块、文字层级、留白及必要的框线形成结构。不同页按内容选布局：双向关系、对照、时间轴、完整案例表等，减少重复感。

### 整稿配色与版型节奏

用户给了纯色页比例的上限时（示例：**严格低于 40%**），按下面的口径统计。按正文主体的配色判断：主要内容只用一套主色、辅以白灰中性色，计为纯色；第二种颜色须在正文主体承担实质内容区分，才计双色/多色。品牌页眉、页码、短装饰线或小点缀不能把纯色页算成双色。

逐页记录分类；默认分母为本轮完整交付稿所有页面（含封面、章节页、附录），如用户限定统计范围则按其要求。交付时说明口径、分母、纯色页数及任何例外/排除理由，不自行用排除页面凑比例。例：60 页稿里 18 页纯色，18/60 = 30%，低于 40% 通过；恰好 40% 不通过。

看连续页缩略图，检查是否重复套用同一版型、色块与阅读节奏；比例达标也需按实际内容调整，不能仅换小点缀过关。用了现成插画素材时，连续页节奏另按 [已有素材与插画](visual-assets.md) 检查。

## 字体

- 示例：PPT 中英文、拉丁字母与数字显式使用一款西文字体（如 **Montserrat**），包括标题、版本号、表格、图表、页码；不能只设置主题后假设混排已正确。
- 中文使用模板指定的中文字体；模板没有指定时，示例为 **Microsoft YaHei**。
- 混排按文字段设置字体，中文保留中文字体；不要对整段强制西文字体导致中文回退。
- Mermaid 的字体栈与 PPT 一致（示例：`Montserrat, Microsoft YaHei, sans-serif`），由渲染配置设定，版面描述与 `build` 不管字体；不能以浏览器回退结果证明 PPT 字体设置正确。
- 字号沿用当前模板；内容溢出时优先处理结构和换行，不能为了塞字不断缩小正文。

## 配色角色（示例）

先按**角色**定颜色，再选具体色值。下表的色值是一套示例；有模板或品牌规范时，把每个角色换成对应的颜色，角色本身保留。

| 用途 | 示例颜色 | 使用方式 |
|---|---|---|
| 主标题、核心强调 | 主色 `#2B4C7E` | 主色 |
| 顶部色带、少量强调 | 强调色 `#3E7CB1` | 不扩散为大面积内容背景 |
| 深色标题 | 深色 `#1B2A41` | 按模板使用 |
| 次级主色 | `#5B7DB1`、`#8FA9CF` | 需要区分层级时使用 |
| 辅助色 | `#A9BCD9` | 次要图形与辅助标记 |
| 浅色内容色块 | `#E8EEF6` | 核心角色或内容组 |
| 正文 | 深灰 `#404040` | 默认正文色 |
| 次要说明、出处 | 中灰 `#6D6D6D` | 不承担关键正文 |
| 分组框线 | 浅中灰 `#B8B8B8` | 细线、克制 |
| 分隔线 | 浅灰 `#D6D6D6` | 结构辅助 |
| 浅灰分区 | `#F2F2F2` | 局部底色、汇总条 |
| 画布 | 白 `#FFFFFF` | 主背景 |
| 黑色 | `#000000` | 必要时使用，不替代整套层次 |

模板自带的其他颜色（如角色区分色、点缀线）保留模板实际值，不当成用户另给的品牌色；无理由不新增颜色。

## 简报语义色整组组合审查（#61）

简报中的核心强调色承载特定认知功能，**必须按「文字、底色、边框、图标」整组组合审查**，不得仅对单字或关键词单列替色：

1. **整组用途先行**：
   - **青绿（`signal-teal`，结论色）**：用于核心定性、已证结论、正面进展、做得到的能力。文字与底色应形成结论感。
   - **洋红（`alert-magenta`，警示色）**：用于风险、警示、失败分支、代价、必须注意的陷阱。整组必须传达醒目的阻断或警惕意图。
   - **浅蓝（`limit-blue`，限定色）**：用于范围限定、成立前提、证据口径、采样规模或估算标签。表达「在此限定下成立」，而非否定或正面结论。
2. **合法搭配组合**：
   - 警示信息：允许「浅洋红底＋洋红边框＋深灰文字」或「透明底＋洋红文字」；
   - 限定信息：允许「浅蓝底＋浅蓝边框＋深蓝/深灰文字」；浅蓝一般作背景或边框，不直接作正文字色（避免对比度不足）；
   - 结论信息：允许「浅青绿底＋青绿边框＋深青绿/深灰文字」或「青绿文字强调」。
3. **禁止冲突组合**：
   - **严禁「洋红警示字＋浅蓝限定底」**：底色不能误当无害中性底，浅蓝底传达限定/条件，洋红字传达危险/警示，二者叠加会造成认知冲突；
   - 空背景文本框不能自动视作中性背景，必须检查其在整页卡片或父容器中的叠加底色；
   - 严禁为了“凑齐三色”在没有限定或风险的页面强加颜色，也不得按单个关键词全局自动替色；
   - 区分图形类别色（数学图表中的蓝/紫原基底与主要变换）与简报语义色，禁止全局文本替色误伤图表类别编码。

## 选定样式的记录与沿用

用户在几个备选样式里明确选定一种后，记下「选中项、适用部位、保留项」，后续沿用，不退回自己偏好的方案，也不把未选的备选混进定稿。

下面是一种常用的**分组框**样式示例（浅灰圆角虚线框），以及它的语义约定：

- 用途：解释段落的归组，例如一条架构关系链。
- 透明或白色内部；细灰线 `#B8B8B8`，参考线宽 1.2px、圆角半径 16px（基于 1280×720 页面）。
- 虚线**分组框**表示内容归组，不表示未完成、未来或不确定；必要时在图例/说明中澄清。它与箭头、关系线的语义分开。
- **连线**的颜色与虚实可区分内容含义，如不同做法或可选路径；页面须有可读图例。同类线在对应图示系统（含其导航缩图）中保持语义一致，不把此约束扩大为全稿所有不同图表必须共用同一套线义。
- 框内有缩排，框外标题与结论保持独立。不要让边框紧贴文字或覆盖内容。
- 不擅自加整圈装饰框或恢复用户没选的装饰；模板页眉原有的装饰可保留。
- Mermaid 示例：`stroke:#B8B8B8,stroke-width:1px,stroke-dasharray:5 5,rx:16,ry:16`。不同渲染器圆角支持可能不同，实际 PPT 使用原生圆角形状。

## 局部修改的判断

“更细化配色”表示优化原有颜色角色与少量分区，不等于换掉整体构图。“更集中”表示保留完整论证、减少无意义拆页，不等于堆满所有资料。“减少重复”表示根据内容变化布局，不等于每页重建视觉系统。
