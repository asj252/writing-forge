# block-beta 版面限制与生成脚本

用 `block-beta` 画逐页草图时读取。下面的限制是在 Mermaid 11.4.1 上实测得来的，别的版本可能不同；以实际使用的渲染器看过为准。

## 限制与写法

1. **上屏文字写在双引号里**，长标签用 `<br/>` 手动换行。`block-beta` 不会自动换行，一个长标签会把整列撑宽。每行能放多少字按页面实际宽度定；脚本默认一行约 20 个汉字，可以改。
2. **嵌套块里不用 `:N` 跨列**。嵌套块（`block:名称 … end`）里只要有一个跨列单元，整个嵌套块的每一列都会被撑到那个单元的宽度（实测同一个长标签：放在最外层跨 2 列，整图约 820 宽；放在嵌套块里不跨列，约 830 宽；放在嵌套块里跨 2 列，约 1650 宽）。跨列只用在最外层，例如标题与底部的结论、出处。`space:N` 在嵌套块里不会撑宽，可以照写。
3. **每一行的宽度加起来等于这一层的 `columns`**，不足用 `space` 补齐。块是按列数依次排的，一行放不下的块会挤到下一行，后面的块跟着错位。
4. **同一层的块一样高**：同一层里最高的块（多行标签或嵌套块）决定这一层每个块的高度，标题、出处这类单行块会被撑高，上下留出大片空白（实测：同层有一个 4 行的嵌套块时，单行的标题与出处都约 160 高，嵌套块里的单行块约 30 高）。这是草图的渲染空白，不代表 PPT 里的比例，交付说明里写明即可。信息密的页因此更容易失衡：先拆页，或改用 `flowchart` 的子图，不要把数据表、限定说明与几条发现硬塞进一张 block 图。
5. **小表格**：`block-beta` 没有表格语法。用一个嵌套块，`columns` 等于列数，逐格写，不跨列；表头格与数据格用不同的 `classDef` 区分（例如表头加底色、加粗）。列多或行多的表留到 PPT 层做成原生表格，草图里写出表头与支撑结论的那几行，并在逐页内容表里注明完整表在 PPT 层。
6. 箭头只表示真实关系，写在所有块定义之后；箭头上的文字也写在双引号里（`A -- "文字" --> B`）。

## 生成脚本 `scripts/blockbeta.py`

只用 Python 3 标准库，不联网，只写 `-o` 指定的文件。Windows 上先设 `PYTHONUTF8=1`，输出才不会乱码。

| 命令 | 做什么 |
|---|---|
| `python scripts/blockbeta.py build P01.json -o P01.mmd` | 按版面描述生成 `block-beta`。按显示宽度自动加 `<br/>`（汉字算 2，西文与数字算 1，不在英文单词与数字中间断开，句读不放行首；自动换行可能断在中文词中，生成后检查，拆词处用 `\n` 强制换行调整）；违反上面第 2、3 条，或字段不对、ID 重复或用了保留字、箭头端点没定义时报错，不写文件 |
| `python scripts/blockbeta.py check P01.mmd … [--terms content.md] [--wrap 40]` | 检查已有的 `block-beta`（手写的也可以）：嵌套块里跨列、一行放不下而错位、上屏文字没加双引号、ID 重复或用了保留字、箭头写在块定义之前、内部代号出现在上屏文字里（错误）；某行超宽、块没有文字（ID 会当文字上屏）、最后一行没填满、行尾注释（提醒）。`columns auto` 或没写 `columns` 的那一层不查行宽。有错误时退出码为 1 |
| `python scripts/blockbeta.py text P01.mmd …` | 逐块列出上屏文字（`<br/>` 还原成连续文字；箭头文字、没有文字的块的 ID 也列出），供同步检查对照逐页内容表；布局注释按素材映射核对，其余按正文核对 |

`--terms` 读一份 Markdown 文件里第一格是「内部代号」的表格（第二格是读者用语），在上屏文字（含箭头文字）里按整词搜代号；同一个块里同时写了读者用语的（代号附了说明）不算，比较时不计空格。

没有 Python 时照上面六条手写，交付前自己逐条核对。

### 版面描述（JSON）

```json
{
  "columns": 4,
  "wrap": 40,
  "rows": [
    [{"id": "T", "text": "页标题", "span": 4, "class": "title"}],
    [{"block": "L", "columns": 1, "span": 2, "rows": [
        [{"id": "L1", "text": "左栏第一条"}],
        [{"id": "L2", "text": "左栏第二条"}]]},
     {"table": "D", "span": 2, "header": ["周", "人数"], "rows": [["第 1 周", "12"], ["第 2 周", "15"]]}],
    [{"id": "S", "text": "出处：报告第 2 节", "span": 4, "class": "src"}]
  ],
  "edges": [["L1", "L2"], ["L2", "D", "支撑"]],
  "classDefs": {"title": "fill:#FFFFFF,stroke:#FFFFFF,font-weight:bold", "src": "fill:#FFFFFF,stroke:#FFFFFF,color:#6D6D6D"}
}
```

- 最外层只认 `columns`（正整数，必填）、`wrap`（不小于 4 的整数，默认 40）、`rows`、`edges`、`classDefs` 五个字段。
- `rows` 的每一项是一行；每行里的项是下面四种之一（一项只能是一种，多写别种的字段会报错），宽度（`span`，正整数，默认 1）加起来等于该层的 `columns`：
  - 文字块 `{"id", "text", "span", "class", "wrap"}`：`text` 是非空的文字（数字也行），其中的 `\n` 是强制换行（自动换行若断在中文词中，可用 `\n` 强制换行调整）；
  - 空位 `{"space": N}`；
  - 嵌套块 `{"block": ID, "columns", "rows", "span", "class"}`，里面的项不能有大于 1 的 `span`；
  - 小表格 `{"table": ID, "header", "rows", "span", "class", "wrap"}`：`header` 与 `rows` 的每一行格数相同，格子是文字或数字；格子的 ID 自动生成（`D_h1`、`D_r1c1`……），表头用 `th`、数据格用 `td` 两个默认样式。
- `edges`：`[起点, 终点]` 或 `[起点, 终点, 箭头文字]`；端点可以是文字块，也可以是嵌套块或小表格的 ID。
- `classDefs`：样式名 → Mermaid 样式文字；用到的样式都要在这里定义（`th`、`td` 有默认值，取自[视觉规范](visual-preferences.md)的示例角色，可以覆盖）。
- ID 用英文字母开头，后接字母、数字或下划线，全页不重复；不能用 `end`、`space`、`block`、`columns`、`class`、`classDef`、`style`、`linkStyle`、`click`、`default` 这些保留字（不分大小写）。

版面描述与生成的 `.mmd` 一起交付；改草图时改版面描述再重新生成，不直接改 `.mmd`，两者才不会分叉。
